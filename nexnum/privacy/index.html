Privacy policy

Last updated: 26 November 2026

In short: NexNum does not collect personal data. There is no account, no advertising and no analytics. Your games and progress stay on your device.

Data stored on your device

The game stores the following information locally, on your device only:

  • your level, XP, badges, missions and day streak;
  • your records, statistics and Daily Challenge results;
  • your preferences (sound, haptics, motion, theme, update settings).

This information is never sent anywhere. Uninstalling the game deletes it.

Sharing

When you share a Daily Challenge result, the game hands a short text (the challenge number, your score and a grid of coloured squares) to the sharing app you choose. Nothing is shared unless you do it yourself.

Permissions

The game does not access your location, contacts, camera or microphone. It may vibrate for haptic feedback. On Android it may ask to install updates, which is used only when you accept an update (see below).

Update check (Android)

Once a day, the game reads a small public file on yallapps.github.io to find out whether a new version is available. The request contains no personal data and no identifier. If you accept an update, the game downloads the installation file from github.com and checks its integrity before opening the Android installer.

These files are hosted by GitHub. Like any web server, GitHub can see the technical information that comes with a request, such as your IP address, under its own privacy statement. YallApps does not receive or store this information. You can turn the automatic check off in Settings › Updates.

This website

This website uses no cookies, no analytics and no third-party fonts or scripts, and stores nothing in your browser. It is hosted on GitHub Pages.

Children

The game collects no personal data from anyone, including children.

Changes

If this policy changes, the new version will be published on this page with a new date.

Contact

Questions about this policy can be asked by opening an issue on github.com/yallapps/nexnum-releases.
